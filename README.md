# 🎵 TasteOfMusic — Сравнение плейлистов Яндекс Музыки

Современное web-приложение для анализа и сравнения двух плейлистов Яндекс Музыки. Находит одинаковые композиции, вычисляет процент совместимости вкусов, находит общих любимых исполнителей и выводит подробную интерактивную статистику в красивом дашборде.

---

## 🌟 Основные возможности

1. **Парсинг любых ссылок Яндекс Музыки**:
   - Новые ссылки вида `https://music.yandex.ru/playlists/lk.0cehello-emy0-4dd0-8173-3dra3e82cad6`
   - Классические ссылки вида `https://music.yandex.ru/users/<login>/playlists/<kind>`
   - Альбомные ссылки вида `https://music.yandex.ru/album/<id>`
   - Режим ручного ввода / вставки HTML страницы или текстового треклиста (`Артист - Трек`).

2. **Интеллектуальное сопоставление (Smart Matching)**:
   - **Точное совпадение по ID трека** (гарантия 100% точности для треков из базы Яндекс Музыки).
   - **Fuzzy-сопоставление** по нормализованным названиям и артистам (удаление ремастеров, deluxe-версий, `(feat. ...)`, лишних спецсимволов).
   - **Анализ общих артистов**: выявление пересечений по любимым исполнителям, даже если конкретные треки не совпадают.

3. **Красивый визуальный дашборд**:
   - **Коэффициент совместимости вкусов** (0–100%) с анимированным круговым индикатором и словесным вердиктом («На одной волне 🌊», «Родственные души 🎧🔥» и т.д.).
   - **Ключевые показатели (KPI)**:
     - Количество одинаковых треков
     - Количество общих исполнителей
     - Общее время совпадающей музыки (часы:минуты:секунды)
     - Доля совпадений относительно каждого из плейлистов
   - **Диаграмма распределения**: интерактивная круговая диаграмма (Chart.js) уникальных и общих треков.
   - **Топ общих артистов**: рейтинг общих музыкантов с количеством треков в каждом плейлисте.

4. **Интерактивный список совпадающих треков**:
   - Мгновенный живой поиск по названию, артисту или альбому.
   - Обложка, название, автор, альбом, хронометраж и бейдж типа совпадения.
   - Прямая кнопка «Слушать» для перехода к треку на Яндекс Музыке.
   - Быстрый экспорт:
     - 📋 **Копировать в буфер обмена** в один клик
     - 💾 **Скачать в формате TXT**
     - 📊 **Экспорт в CSV** (для Excel и таблиц)

5. **Вкладки детального исследования**:
   - `🎯 Совпадающие треки`
   - `🎵 Все треки Плейлиста 1` (с подсветкой совпадений)
   - `🎶 Все треки Плейлиста 2` (с подсветкой совпадений)

## 🚀 Запуск приложения

### 1. Установка зависимостей (если запускается на новом окружении):
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера:
```bash
python run.py
```
или:
```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 3. Открытие в браузере:
Перейдите по адресу:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

---

## ⚡ Быстрый старт и демонстрация

- Нажмите кнопку **«Загрузить пример»** в шапке или **«Вставить тестовые ссылки»** над полями ввода.
- В поля автоматически подставятся реальный плейлист из вашего запроса (`lk.0ce106d6-e6c0-4dd0-8173-3dba3e82cad6`) и второй плейлист для сравнения.
- Нажмите **«Сравнить плейлисты»** и наслаждайтесь результатами!
